# Week 5 - SPA Simulation

A simple Single Page Application simulation using HTML, CSS and Vanilla JavaScript.

Features: hash routing, dynamic project cards, project detail routes, browser navigation events, 404 handling and mobile navigation.

Routes: #/, #/projects, #/projects/1, #/projects/2, #/projects/3, #/services, #/about.

This is intentionally a learning-level project and uses no framework or backend.
